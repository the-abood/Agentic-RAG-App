# Agentic-RAG-App
End-to-end agentic RAG app: LangChain + FAISS retrieval over custom documents, real-time web search with Tavily, and a CrewAI multi-agent team (Researcher, Writer, Critic, Trend Analyst, Report Generator) powered by Groq. Includes PCA/t-SNE embedding visualisation and Markdown/PDF report export.
